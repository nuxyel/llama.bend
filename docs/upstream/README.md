# Repros for open Bend issues

The programs behind the `bendlang/bend` issues I opened from this project that are still open, so anyone can run
them. The issue texts themselves live in the issues.

| File | Issue |
|---|---|
| `fork_wake.bend`, `fork_wake.sh` | [#2141](https://github.com/bendlang/bend/issues/2141): a small parallel let wakes every worker thread, and the sequential code between lets runs slower |

When an issue closes, its files leave this folder.
